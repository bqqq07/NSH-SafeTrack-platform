## 1. الفكرة باختصار

مسار تعليمي **كامل** يعلّم Python لشخص **من الصفر**، من أول `print("hello")` إلى كتابة أدوات حقيقية، ثم ينتهي بمسار **Python للأمن السيبراني** (دفاعي وأخلاقي).

- **اللغة:** الشرح عربي بسيط، والكود دايماً إنجليزي (كما هو في الواقع). المصطلحات: `Variable (المتغير)`.
- **المتعلم:** نفس متعلم المنصة: ما يعرف إنقلش ولا برمجة، ووقته محدود (دروس 8–12 دقيقة).
- **الأهم:** يكتب كود ويشغّله **داخل المنصة** من أول درس. بدون تثبيت أي شي، وعلى الجوال.
- **الهدف النهائي:** يقدر يبني بنفسه أدوات أتمتة وتحليل (مثل تحليل سجلات دخول وكشف التخمين) ويفهم Python بما يكفي ليكمل بنفسه.

### وش يختلف عن مسار الأمن؟
| | مسار الأمن (موجود) | مسار Python (الجديد) |
|---|---|---|
| طبيعة التمرين | قراءة واختيار وترتيب | **كتابة كود وتشغيله** |
| وقت التعلم | ساعات قليلة لكل مستوى | تراكمي، يحتاج ممارسة يومية |
| الصعوبة | مفاهيم | **مهارة** (تحتاج تكرار وأخطاء كثيرة) |

## 2. من هو المتعلم؟ وقيود الجوال ⚠️

| البند | التفصيل |
|---|---|
| المستوى | مبتدئ تماماً في البرمجة |
| اللغة | عربي، قراءته للإنجليزي محدودة |
| الجهاز | جوال غالباً، ولابتوب أحياناً |
| الوقت | متقطع بسبب الدوام: 10–20 دقيقة |
| الدافع | مهارة جديدة، تطوير في الأمن السيبراني |

### أكبر تحدٍ: **الكتابة على الجوال**
كتابة الكود على الجوال صعبة (رموز كثيرة، مسافات بادئة، تصحيح تلقائي يخرّب الكود). التصميم لازم يحل هذا من البداية:

1. **شريط رموز** فوق الكيبورد: `: ( ) [ ] { } " ' = _ # . , +` وزر **Tab** (إزاحة).
2. **تعطيل التصحيح التلقائي** والحروف الكبيرة التلقائية داخل المحرر.
3. **تمارين تقلل الكتابة** في البداية: ترتيب أسطر (Parsons)، إكمال الفراغات، اختيار الناتج، إصلاح خطأ صغير.
4. **شرائح كود جاهزة** (Snippet chips) تضغطها وتنزل في المحرر.
5. **وضع أفقي** للمحرر، وخط كود كبير قابل للتحكم.
6. المشاريع الطويلة تُوصى على لابتوب (ويقدر يكمل من الجوال).
7. **حفظ المسودة تلقائياً** لكل تمرين.

## 3. مبادئ التعليم (Learning Design)

1. **شغّل قبل ما تفهم:** يرى الكود يشتغل أولاً، ثم نشرحه.
2. **توقّع → شغّل → عدّل (Predict – Run – Modify):** نسأله "وش بيطلع؟" قبل التشغيل.
3. **مثال محلول ثم تمرين مشابه** (Worked Example → Faded Example → Free). نخفي جزءاً من الحل تدريجياً.
4. **الأخطاء صديقتك:** درس مخصص لقراءة رسائل الخطأ، وكل خطأ يظهر بشرح **بالعربي** (انظر القسم 8).
5. **تكرار متباعد للصياغة (Syntax):** بطاقات صغيرة: "وش تكتب لتعرّف قائمة؟".
6. **تلميحات تدريجية:** تلميح 1 ← تلميح 2 ← الحل، وشرح ليش الحل صحيح.
7. **مشروع صغير كل مستوى** يجمع اللي تعلّمه.
8. **أمثلة من حياتنا:** ريال، فاتورة STC، أوقات الصلاة، رسوم، نتائج اختبار... بدل `foo/bar`.
9. **لا تعلّم أدوات ضارة:** كل أمثلة الأمن دفاعية ومحلية (انظر القسم 12).
10. **لا نقفل على المتعلم:** يعيد التمرين بدون حد، لكن القفل المتسلسل للدروس (موجود في المنصة).

### 5.2 هيكل الدرس البرمجي

```
1. 🎯 الهدف
2. 🌟 مثال شغّال (شغّله وشوف)               ← Run it first
3. 🔍 توقّع: وش بيطلع لو غيّرنا كذا؟       ← Predict
4. 📖 الشرح البسيط (تشبيه + رسم)
5. 🔤 المصطلحات (English | النطق | العربي)
6. 🧪 تمرين محلول جزئياً (Fill / Parsons)
7. ⌨️ تمرين حر مع اختبارات تلقائية
8. 🐞 أصلح الخطأ
9. ✅ اختبار سريع (3–4 أسئلة)
10. 📝 ملخص + بطاقات الصياغة
```

### 5.3 مبدأ "جرّب بنفسك"
- زر **تشغيل ▶** و**إعادة تعيين ↺** و**عرض الحل** (بعد محاولتين).
- تلميحات تدريجية، وشرح بعد الحل: **"ليش هذا الحل يشتغل؟"** وحل بديل أنظف أحياناً.
- يقدر يحفظ كوده ويرجع له، وينزّله كملف `.py`.

## 6. التنفيذ التقني (اقتراح) 🛠️

> القرار النهائي لـ Claude Code حسب الأنسب. **القيد الأساسي:** الاستضافة Namecheap مشتركة (PHP + MySQL فقط)، فتشغيل Python على السيرفر **غير ممكن وغير آمن**.

### 6.1 تشغيل Python داخل المتصفح

| الخيار | المزايا | العيوب |
|---|---|---|
| **Pyodide** (Python كامل مترجم لـ WebAssembly) | Python حقيقي، يدعم `re hashlib json csv sqlite3 datetime` وغيرها، أكثر دقة | تحميل أولي ~7–10MB، أبطأ على الجوالات الضعيفة |
| **Skulpt / Brython** | أخف (~1MB) وأسرع تحميلاً | ناقص: مكتبات كثيرة غير مدعومة، سلوك مختلف أحياناً |
| تشغيل على سيرفر (API) | ما يثقل الجوال | **ممنوع** هنا: ثغرة تنفيذ كود عن بعد + الاستضافة لا تدعمه |

**التوصية:** Pyodide مع:
- **تحميل كسول** (Lazy): ما يتحمّل إلا لما يوصل المتعلم لأول درس كود.
- **شريط تقدم** وتوضيح الحجم.
- **تخزين دائم** عبر Service Worker (يتحمّل مرة وحدة ويشتغل Offline).
- **تشغيل الكود في Web Worker** (ما يجمّد الواجهة) مع **مهلة تنفيذ** (مثلاً 5 ثواني) وإمكانية الإيقاف.
- **وضع خفيف** (Lite) لو التحميل فشل: الدروس تُقرأ والتمارين تتحول لاختيارات.
- استضافة ملفات Pyodide **محلياً على الموقع** (Self-host) بدل CDN، حتى ما نعتمد على طرف خارجي.

### 6.2 المحرر
- **CodeMirror 6** (خفيف وممتاز للجوال) أو محرر مخصص بسيط.
- اتجاه **LTR** داخل المحرر حتى لو الصفحة RTL.
- ترقيم أسطر، تلوين Python، إزاحة تلقائية بعد `:`، **شريط رموز للجوال**.
- تعطيل `autocapitalize / autocorrect / spellcheck`.

### 6.3 مدخلات ومخرجات
- `print` يظهر في لوحة ناتج.
- `input()`: واجهة تسأل المتعلم داخل الصفحة (أو مدخلات جاهزة يحددها التمرين).
- **ملفات افتراضية (Virtual FS)**: كل تمرين يزوّد ملفات تدريبية (سجلات، CSV) داخل ذاكرة المحرك.
- **لا شبكة**: كود المتعلم لا يتصل بالإنترنت. أمثلة `requests` و`socket` تعمل على **خدمة محاكاة داخل الصفحة** مصممة لذلك.

### 6.4 الفحص التلقائي (Autograder)

  "starter": "price = 100\n# اكتب الحل هنا\n",
  "tests": [

## 8. شرح الأخطاء بالعربي 🆘 (ميزة مميزة)

رسالة الخطأ الإنجليزية مخيفة للمبتدئ. نلتقطها ونعرض بجانبها:
- **وش معناها ببساطة**
- **السبب الأشهر**
- **كيف تصلحها**
- **الجزء المهم** من الـ Traceback (السطر ورقمه) بتلوين.

| الخطأ | الشرح المقترح |
|---|---|
| `SyntaxError` | فيه خطأ في كتابة الكود: نسيت نقطتين `:` أو قوس؟ |
| `IndentationError` | المسافات البادئة غير صحيحة، اضغط Tab بشكل متسق |
| `NameError` | استخدمت اسماً غير معرَّف، تأكد من التهجئة |
| `TypeError` | دمجت أنواعاً مختلفة (نص + رقم)، حوّل بـ `str()` |
| `ValueError` | القيمة ما تناسب التحويل (`int("abc")`) |
| `IndexError` | رقم العنصر أكبر من طول القائمة |
| `KeyError` | المفتاح غير موجود في القاموس |
| `ZeroDivisionError` | قسمة على صفر |
| `FileNotFoundError` | الملف غير موجود أو المسار غلط |
| `AttributeError` | الكائن ما عنده هذي الخاصية/الأسلوب |
| `RecursionError` | دالة تنادي نفسها بلا نهاية |
| تشغيل بلا نهاية | تنبيه المهلة: "حلقتك ما تنتهي؟ تأكد من شرط التوقف" |

## 9. استراتيجية المحتوى (كيف نكتب بشكل ممتاز)

3. **أمثلة سعودية/عملية:** فواتير، رواتب، نسب، أوقات، أسماء مدن، رموز أمنية.

6. **رسومات متحركة** لأفكار صعبة (الحلقات، الذاكرة، استدعاء الدوال).
7. **تنبيهات ملونة:** ⚠️ فخ شائع، 💡 نصيحة، 🧠 معلومة، 🚫 لا تسوي كذا.
8. **مراجعة بشرية** لكل درس (دقة + لغة + مستوى الصعوبة).
9. **نبرة مشجعة:** البرمجة صعبة أول مرة، نذكّره إن الغلط جزء من التعلم.
