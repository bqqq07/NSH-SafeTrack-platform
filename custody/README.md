# نظام العهدة

موقع PHP + MySQL (يعمل على استضافة Namecheap المشتركة / cPanel بدون أي أدوات إضافية).
كل البيانات والصور (الفواتير والتواقيع) تُخزَّن في قاعدة MySQL.

## التركيب على Namecheap
1. من cPanel ← **MySQL Databases**: أنشئ قاعدة ومستخدماً وأعطه كل الصلاحيات.
2. ارفع محتويات مجلد `custody/` إلى `public_html` (أو Subdomain مثل `custody.yourdomain.com`).
3. انسخ `config.sample.php` إلى `config.php` وعدّل بيانات القاعدة.
4. افتح `https://yourdomain/setup.php` ← ينشئ الجداول وأول مستخدم (اسم + كلمة مرور).
5. **احذف `setup.php`** من السيرفر.

## المزايا
- **الاستلام**: مبالغ بتواريخ متفرقة.
- **الصرف** (البنود): سلفة (مفصولة عن الرصيد) · مشتريات ونواقص · وجبات · صيانة وإصلاحات · مواصلات · أخرى (تذكر) · إيجارات (مخازن / سكن / أخرى تذكر) · شحن بضائع · يومية خدمات.
- كل صرف: المبلغ، التاريخ، البيان، **توقيع بالإصبع**، **فاتورة اختيارية** (تُضغط في المتصفح ثم في السيرفر إلى 1280px/JPEG لتخفيف التقرير).
- **التقارير**: يوم محدد أو فترة، مع فلتر العهدة والبند، رصيد مرحّل، مجاميع لكل بند، السلف في قسم منفصل، إرفاق صور الفواتير اختياري، طباعة / حفظ PDF من المتصفح، وتصدير CSV لـ Excel.
- رصيد العهدة = المستلم − المصروفات (**بدون السلف**، تُعرض منفصلة).
- يدعم أكثر من عهدة (صفحة "العُهد") والأرقام العربية في المبالغ.

## الأمان
كلمات المرور مشفّرة (`password_hash`)، حماية CSRF، استعلامات PDO محضّرة، الصور تُعاد معالجتها بـ GD ولا تُقدَّم إلا لمستخدم مسجّل (`file.php`)، وملف `config.php` محمي بـ `.htaccess`.
